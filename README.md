# ArduND

ハイデンハイン（HEIDENHAIN）社製 1軸用表示カウンター ND200シリーズ（ND221B, ND287 等）のデータ転送用RS-232Cポートと接続し、TCP/IP（Ethernet）経由で現在値を取得するためのシリアル-イーサネット変換アダプタ用ファームウェアです。

---

## 概要・位置づけ

- **専用ファームウェア**:
  本リポジトリは ND200シリーズカウンター専用の制御ファームウェアです。
- **ハードウェア基板**:
  標準シリアル-イーサネット変換ボード **[ETH-574](https://github.com/BLG-SAGA-LS/ETH-574)** を採用しています。
  回路図や基板設計・ピンアサイン等の詳細なハードウェア設計情報については、上記 ETH-574 リポジトリを参照してください。
- **ETH-574 汎用ファームウェア（UNESCO）との違い**:
  本機はND200シリーズ専用のアプライアンスとして動作するため、ETH-574標準の汎用プロトコル探査ファームウェア「UNESCO」とは初期設定方法やTCP通信仕様が異なります。

---

## 基本仕様

- **ネットワーク通信**:
  - ポート番号: TCP `7777`
  - 接続時、または接続中に `?` / `GET` コマンドを送信することで、カウンターから取得した現在値文字列が返信されます。
  - 切断コマンド: `~` / `BYE` / `QUIT` / `EXIT`
- **カウンター側RS-232C通信**:
  - 9600 bps, 7ビット, 偶数パリティ, ストップビット2 (7E2) 固定
- **初期設定（IP / MACアドレス）**:
  - PCとUSBシリアル接続（9600 bps, 8N1, 送受信改行 CR+LF）し、`!IPA` / `!MAC` コマンドにより本体EEPROMへ設定を保存します。
