# ArduND

ハイデンハイン（HEIDENHAIN）社製1軸用表示カウンター ND200シリーズ（ND221B, ND287 等）のデータ転送用RS-232Cポートと接続し、TCP/IP（Ethernet）経由で現在値を取得するための変換アダプタ用ファームウェアです。

---

## 概要

ArduNDは、ND200シリーズカウンターの現在値をネットワーク経由でポーリング取得するための専用アプライアンスとして動作します。
クライアントからTCPポート `7777` に接続するか、接続中に `GET` や `?` コマンドを送出することで、内部でカウンターに対してデータ転送要求（`0x02` / STX）を発行し、得られた現在値文字列をTCPクライアントへ返却します。

---

## ハードウェア仕様

本システムのハードウェア基板には、標準シリアル-イーサネット変換ボード **[ETH-574](https://github.com/BLG-SAGA-LS/ETH-574)** を採用しています。
回路図・基板アートワーク・ピンアサイン等の詳細なハードウェア設計情報については、上記 [ETH-574 リポジトリ](https://github.com/BLG-SAGA-LS/ETH-574) を参照してください。

- **マイコン**: Arduino Pro Micro 5V版 (ATmega32U4 / 16MHz)
- **Ethernetコントローラ**: WIZnet W5500 SPI モジュール (CS: D10)
- **RS-232Cトランシーバ**: ANMBEST MAX3232 モジュール (Serial1: D1 TXD, D0 RXD)
- **RS-232Cコネクタ**: D-Sub 9ピン (DE-9) オス
- **電源供給**: マイクロUSB Type-B コネクタ（5V / 1A 以上）
  - PC接続によるIP/MACアドレス設定時はデータ通信対応USBケーブルを使用します。
  - 通常運用時は充電・給電専用USBケーブルでも動作可能です。

---

## 使用手順

### 1. 接続および起動
1. **通電していない状態**で、ND200シリーズカウンターと本機を専用シリアルケーブルで接続します。
2. LANケーブルを本機のRJ-45ポートに接続します。
3. USBケーブルを接続し、電源を投入します（赤色LEDが点灯）。

### 2. 停止手順
1. USBケーブルを取り外し、電源を切断します。
2. LANケーブルを取り外します。
3. シリアルケーブルを取り外します。

> [!WARNING]
> シリアルケーブルの活線挿抜は機器損傷の原因となるおそれがあります。必ず電源切断状態で接続・取り外しを行ってください。

## ネットワーク初期設定（USBシリアル経由）

本機のIPアドレスおよびMACアドレスは、PCとUSBケーブルで接続し、シリアル通信コンソールからEEPROMに書き込んで設定します。

### シリアルポート通信条件
- **ボーレート**: 9600 bps
- **データビット**: 8
- **パリティ**: なし
- **ストップビット**: 1
- **フロー制御**: なし
- **改行コード**: 送受信ともに `CR+LF`
- **PC側認識名**: 「Arduino Leonardo」等として認識されます。

### 設定コマンド一覧

| コマンド | 説明 | 実行例 |
| :--- | :--- | :--- |
| `?` / `?HEL` / `HELP` | ヘルプメッセージを表示します。 | `HELP` |
| `?IPA` | 現在設定されているIPアドレスを表示します。 | `?IPA` |
| `!IPA <IPアドレス>` | IPアドレスを設定しEEPROMに保存します。 | `!IPA 192.168.0.1` |
| `?MAC` | 現在設定されているMACアドレスを表示します。 | `?MAC` |
| `!MAC <MACアドレス>` | MACアドレスを設定しEEPROMに保存します。 | `!MAC FE:FF:00:00:00:01` |

> [!IMPORTANT]
> `!IPA` および `!MAC` による設定変更後は、一度USBケーブルを抜いて電源を再投入（再起動）しないと新しいネットワーク設定が反映されません。

## TCP/IP 制御プロトコル仕様

TCPクライアントから本機のIPアドレス、ポート `7777` へ接続して通信します。

- **ポート番号**: `7777`
- **通信形式**: ASCIIテキスト、改行コード `CR+LF`
- **接続制御**: 
  - 最初に接続したクライアントとセッションを維持します。
  - 2番目以降に接続してきたクライアントに対しては、現在値を返した直後に本機側からTCP切断を行います。

### コマンド体系

| コマンド | 応答 | 説明 |
| :--- | :--- | :--- |
| *(接続時)* | 現在値文字列 | TCP接続が確立された際、挨拶代わりに即座に現在値を1回返却します。 |
| `?` または `GET` | 現在値文字列 / `ERROR` | ND200シリーズカウンターに対して現在値要求を発行し、得られた文字列を返します。 |
| `~` または `BYE`, `QUIT`, `EXIT` | なし（切断） | 本機とのTCP接続を切断・解放します。 |
| *(その他の文字列)* | `ERROR` | 未定義コマンドに対するエラー応答です。 |

### カウンター側通信仕様（参考）
- 本機内部のRS-232C通信設定: **9600 bps, 7ビット, 偶数パリティ (Even), ストップビット2 (SERIAL_7E2)**
- 本機からカウンターへ `0x02` (STX) を1バイト送信すると、カウンターから現在値文字列（符号・数値・単位・ステータス等を含む約13文字のASCIIテキスト）が返信されます。
- 最大100回（1回あたり待機・リトライ）の取得試行を行い、正常に取得できなかった場合は `ERROR` を返します。

## RS-232C ケーブル結線について

ND200シリーズ（ND221B, ND287等）のシリアルコネクタ形状やピンアサインは機種によって異なります。
フロー制御線の処理等が必要となる場合があるため、市販の一般的なストレート/クロスケーブルでは正常に通信できないことがあります。

結線の詳細やピンアサイン図については、付属の [取扱説明書 (PDF)](doc/Manual_ArduND.pdf) を参照してください。
